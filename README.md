# 图库中 / TUKUZHONG

### 相册神经图谱 · Gallery Graph

> **核心设计理念**：
> “图库中”不是另一款按文件夹排列的传统相册，而是以**图谱**作为索引入口，以**展厅**作为观看方式。**足迹**、**长卷**、**目录**，则分别提供**空间**、**时间**和**来源**这三种整理照片的视角。五个入口查看的应是**同一批作品**，切换的是组织和浏览方式，而不是五份互不相干的相册。

---

## 🌟 五个统一视角 (Five Unified Perspectives)

| 入口                           | 视角维度                       | 核心体验与功能                                                                                                                                                                                                         |
| :----------------------------- | :----------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **🌐 图谱 (Graph)**      | **关系总览与索引入口**   | 照片与视频作为核心节点，按导入目录、拍摄时间、地理城市与相机机型建立神经拓扑关系。点击任意节点直达对应作品集合；关系严格基于真实元数据，缺少信息明确显示“未知”，绝不伪造参数；内置“问问你的相册图谱”智能分析检索。 |
| **🏛️ 展厅 (Gallery)**  | **主要观赏与舞台体验**   | 以单件作品为核心舞台，提供上一件/下一件无缝切换、作品档案与完整 EXIF 参数（光圈、快门、ISO、焦距、机型、镜头）；照片与动态视频在同一套流程中沉浸播放与观赏；底部常驻胶片传送带。                                       |
| **📍 足迹 (Footprints)** | **空间视角**             | 汇聚具备真实 GPS 坐标的作品，形成地理聚集与光点呈现；无 GPS 作品单独归入“未定位”，不混入地图（当前版本显示“功能开发中”）。                                                                                         |
| **📜 长卷 (Scroll)**     | **可连续阅读的时间叙事** | 摒弃生硬的普通网格，以年、月作为章节骨架，节奏排版呈现时空记忆流。点开任一作品后，前后浏览顺序与长卷中的时间流严格一致。                                                                                               |
| **📁 目录 (Catalog)**    | **来源与应用内逻辑影集** | 导入来源与集合管理页。支持查看目录详情、目录内搜索、重命名、向目录追加作品，以及从图库中移除目录（仅删除应用索引，绝不删除本地原文件）。                                                                               |

---

## ✨ 核心特性

- **动静结合全链路**：完整支持高分辨率静态摄影原片与动态视频（`.mp4`, `.mov`, `.webm`, `.mkv` 等），原生播放器流畅播放。
- **100% 本地隐私安全**：纯本地运算，基于浏览器 IndexedDB 与 LocalStorage 实现资产二进制与拓扑结构持久化，无任何数据上传云端。
- **真实元数据原则**：坚守参数真实性，无 EXIF 或地理信息时真实呈现“未知”或“未定位”。
- **神经动态物理引擎**：高保真发光神经纤维连线与仿生水母交互节点，微秒级 Spring 弹性动力学。
- **跨平台现代化架构**：基于 Expo & React Native Web，适配现代浏览器与移动端。

## 🚀 快速启动 (Getting Started)

### 1. 克隆代码仓库

```bash
git clone https://github.com/colstyle/TUKUZHONG.git
cd TUKUZHONG
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
# 或
npx expo start --web
```

启动后在浏览器中打开：`http://localhost:8081/` 即可沉浸体验。

## 🛠️ 技术栈 (Tech Stack)

- **框架**：React Native, Expo SDK
- **语言**：TypeScript (严谨类型安全，`npx tsc --noEmit` 0 报错通过)
- **图形与动效**：Canvas 2D / WebGL 硬件加速、Spring 物理弹性算法
- **存储**：IndexedDB (二进制媒体持久化) + Web Storage
- **多媒体**：HTML5 Video API、EXIF 摄影光学解析器
